<objective>
Build the first conversational progress-to-Plane loop: parse the user's daily update, resolve safe Plane targets, preview planned changes, optionally apply confirmed comments through the Plane API writer, and save an audit trail.
</objective>

<must_haves>
- User can pass the seed Chinese progress message to one command.
- Output includes parsed events, resolution status, warnings, and planned Plane changes.
- Ambiguous or unresolved targets are not applied silently.
- Resolved comment changes can be applied through Plane API only when `--apply` and `PLANE_API_KEY` are present.
- Each run writes an audit artifact under ignored `exports/progress/`.
</must_haves>
