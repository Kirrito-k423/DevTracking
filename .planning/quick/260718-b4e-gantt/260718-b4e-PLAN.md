# Gantt 右侧两级详情抽屉

## 目标

任务条或事件首次点击时，仅在页面右侧展示一级摘要详情；图片、文档、上传和删除等资料能力放进抽屉内部的二级资料栏，需再次点击“资料与附件”后才展示。

## 任务

- [x] 将底部详情面板恢复为右侧抽屉，并适配桌面与移动端。
- [x] 增加资料入口和抽屉内二级资料栏，保留附件上传、预览、下载、删除逻辑。
- [x] 完善返回、关闭、Esc 和详情刷新行为，避免二级栏状态错乱。
- [x] 重新生成页面并完成自动化、桌面和移动端视觉验收。

## 验收

- 一级抽屉首次打开时看不到附件上传区和附件列表。
- 点击“资料与附件”后，二级栏从一级抽屉内部滑入并可返回。
- 任务与事件均支持二级资料栏，附件数量正确。
- 图片预览、文件下载、上传和删除功能保持可用。
- `Esc` 按图片预览、二级栏、一级抽屉的层级依次关闭。
