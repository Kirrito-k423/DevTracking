# 双需求页面、事件新鲜度排序与任务 Pin

## 目标

把紧急性拆成“版本必做”和“预埋技术”两个结构相同的 Gantt 子页面；每个页面仍通过上下位置表达重要性，但未固定任务会根据最近事件时间自动排序，长期无新事件的任务逐步下沉。

## 任务

- [x] 增加双页面切换与向后兼容的任务分类字段，旧任务默认归入“版本必做”，移动父任务时整棵子树一起移动。
- [x] 按同级任务最近事件时间自动排序，保持父子层级连续，并让新事件在当前页面即时提升任务位置。
- [x] 增加任务行 Pin 按钮；固定任务保留当前同级排序槽位，未固定任务继续围绕固定槽位自动重排。
- [x] 扩展本地快照、changeset 和新任务字段，保持旧 schema/localStorage 标识以及附件、导入导出兼容。
- [x] 运行单元测试、JavaScript 语法检查和真实浏览器双页面/Pin 交互验证，并同步到 8090 服务。

## 验收

- 顶部可在“版本必做”和“预埋技术”之间切换，两个页面共享完整 Gantt 能力。
- 没有分类字段的历史任务仍出现在“版本必做”。
- 同一父任务下，最近有事件的未 Pin 任务排在更上方；长期无事件任务排在后面。
- Pin 后任务保持当前槽位，其他任务仍可自动变化；取消 Pin 后重新加入自动排序。
- 新增任务继承父任务分类，无父任务时归入当前页面。
