# Gantt 完成任务自动隐藏

## 目标

默认隐藏已完成任务及其全部子任务；提供“全部显示”按钮临时恢复完整任务树，并可再次切回隐藏模式。

## 任务

- [x] 统一识别完成状态，并从任务行、时间轴、事件标记和未来事件预警中隐藏完成任务子树。
- [x] 在工具栏增加“全部显示 / 隐藏已完成”切换按钮，全部显示时展开任务树。
- [x] 完成任务编辑保存后立即更新视图，不改动历史数据 schema 或 localStorage 标识。
- [x] 运行自动化测试、脚本语法检查和真实浏览器交互验证，并同步到 8090 本地服务。

## 验收

- 页面刷新后，状态为完成、进度为 100% 或带完成时间的任务默认不可见。
- 完成父任务时，其所有后代任务一并隐藏。
- 点击“全部显示”后可看到完整任务树；按钮切换为“隐藏已完成”，点击后恢复默认过滤。
- 现有任务数据、附件、导入导出与自动保存保持兼容。
